## 🚀 1-Click Render.com Deployment (With SPA Static Serving)

This repository includes **Single-Page Application (SPA) Static Serving** in `backend/main.py` and a **`render.yaml`** Blueprint.

1. Go to your **[Render Dashboard](https://dashboard.render.com)**.
2. Click **`+ New`** ➔ **`Blueprint`**.
3. Select your repository (`Code-Stride/jarvis-mark-i`).
4. Click **`Apply`** — Render will automatically build the React frontend and serve both the **Stark-Tech Web HUD** and **FastAPI Backend + WebSockets** on your Render URL!
